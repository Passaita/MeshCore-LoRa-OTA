LoRa-OTA

Firmware updates over LoRa for MeshCore repeaters. A dated record of what the project designed, built and tested, and where it stands.

Last updated 12 Nov 2026 · RAK3401 · Heltec V4

What this project is

Solar repeaters sit on roofs, masts and hills. Updating their firmware usually means a trip, a cable or a phone close by.

LoRa-OTA lets a MeshCore repeater fetch a new firmware over the LoRa mesh itself, check it, and install it. No site visit.

Mesh traffic always goes first. An update uses only a small, fixed share of airtime and waits for quiet air.

Hardware: RAK3401 (nRF52840 + SX1262, 1 W booster) and Heltec V4 (ESP32-S3 + SX1262). Built on MeshCore, with its power-saving features kept.

  1. Find - a node asks its circle who holds a version.
  2. Pull - it fetches the image chunk by chunk, encrypted.
  3. Check - CRC and SHA-256 over the whole image.
  4. Install - the bootloader installs it at the next start.
  5. Serve - the node now offers it to its neighbours.

Concepts

Swarm: pull a version, not a host

A node asks for a version and fetches it from the best holder in reach. If that holder goes quiet, the pull continues from another one. Pullers of the same image share one stream.

Circle encryption

Nodes of one owner share a passphrase. Outsiders do not see the service. Each pull gets its own session key; every chunk is encrypted. No admin password on air.

Fair airtime

LoRa-OTA uses only a set share of airtime. Relays are counted, so a pull through several repeaters slows down on purpose. Mesh traffic always goes first.

Fleet fill and push

A pull also fills empty slots of nodes that overhear it. A push asks the circle to fetch a new version over several days. Filling and installing stay separate steps.

One slot, then A/B

The first design used one staging slot. Next: two app slots. The new app starts on trial; after 3 failed trial boots the previous one returns by itself.

Delta updates

Most of a new version equals the old one. Patches measured about 8-35 KB against about 233 KB for a whole image. Less airtime, faster updates.

Size

A smaller app means fewer chunks per update and room for two slots. Build settings alone saved about 57 KB (16 %).

Safety net

A hardware watchdog restarts a hung node. A node stuck in a boot loop opens Bluetooth recovery by itself. Bluetooth and USB recovery always stay available.
